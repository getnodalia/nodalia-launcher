Nodalia Launcher portable mode

While this file sits next to nodalia-launcher.exe, Nodalia Launcher keeps its settings, its
download cache and its record of installed apps in the NodaliaLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Nodalia Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Nodalia Launcher) instead.
If NodaliaLauncherData can't be written (for example on a read-only drive), Nodalia Launcher says
so and uses %APPDATA%\Nodalia Launcher instead.
