Nodalia Launcher 0.2.0 arregla las instalaciones en macOS, las notas de versión y las ventanas emergentes.
*Nodalia Launcher 0.2.0 fixes macOS installs, release notes and dialogs.*

## Español

### Novedades

- **Las apps de macOS sin firma de Apple se instalan**: la suma SHA-256 de la descarga sigue siendo obligatoria, pero la firma de código ya no es un requisito. Antes, apps como Vinilo (que incluye Electron) fallaban con un error de firma. Si `codesign` tiene alguna objeción, queda en el registro y la instalación continúa.
- **Notas de versión normalizadas**: se muestran en tu idioma (la versión en español o en inglés, no las dos), con títulos, listas, negrita, cursiva y código bien formateados, y sin los apartados vacíos.
- **Notas incluso sin cuota de GitHub**: cuando se alcanza el límite de la API, el launcher lee las notas del propio repositorio de cada app y todas las sumas de comprobación (`SHA256SUMS`, `SHA256SUMS-macos` y `SHA256SUMS-windows`), así que Letra y el resto de apps con DMG se pueden instalar sin esperar a que se renueve el límite.
- **Ventanas emergentes bien encuadradas**: esquinas redondeadas que coinciden con la ventana, y en macOS ya no asoma una esquina bajo los controles de la ventana.
- **Errores traducidos**: los mensajes de error de la instalación y de la red (descarga, suma de comprobación, instaladores del sistema, Flatpak, Windows Installer…) salen en tu idioma, con el detalle técnico al lado; lo que no tiene traducción propia aparece dentro de una frase traducida.
- **Icono de la barra de menús de macOS del tamaño estándar**: con el margen de los iconos del sistema, en lugar de ocupar toda la altura de la barra.
- **Más fiable en Windows**: detecta las apps instaladas en la carpeta `Nodalia\<Nombre>` aunque el nombre visible lleve tildes (Lámina).
- El launcher sigue **actualizándose solo** con el mismo flujo que las demás apps.

## English

### What's new

- **macOS apps without an Apple signature install**: the download's SHA-256 sum is still required, but a code signature no longer is. Before, apps such as Vinilo (which bundles Electron) failed with a signature error. If `codesign` has an objection it is logged and the install goes on.
- **Tidy release notes**: shown in your language (the Spanish or the English half, not both), with headings, lists, bold, italics and code formatted properly, and no empty sections.
- **Notes even without GitHub quota**: when the API limit is reached, the launcher reads the notes from each app's own repository and every checksum list (`SHA256SUMS`, `SHA256SUMS-macos` and `SHA256SUMS-windows`), so Letra and the other apps that ship a DMG can be installed without waiting for the limit to reset.
- **Dialogs that sit right**: rounded corners that match the window, and on macOS no corner shows beneath the window controls.
- **Translated errors**: install and network error messages (download, checksum, system installers, Flatpak, Windows Installer…) appear in your language with the technical detail beside them; anything without its own translation is wrapped in a translated sentence.
- **Menu bar icon on macOS at the standard size**: with the margin of the system's own icons instead of filling the bar's whole height.
- **More reliable on Windows**: finds apps installed in the `Nodalia\<Name>` folder even when the display name has accents (Lámina).
- The launcher still **updates itself** through the same flow as the other apps.
