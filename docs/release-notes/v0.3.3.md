Nodalia Launcher 0.3.3 vuelve a ofrecer Buzón cuando GitHub ha limitado las peticiones.
*Nodalia Launcher 0.3.3 offers Buzón again when GitHub has rate-limited the requests.*

## Español

### Correcciones

- **Buzón «No disponible aquí»**: cuando GitHub limitaba las peticiones sin cuenta, el Launcher averiguaba los archivos de una release solo por sus listas de sumas `SHA256SUMS`, `-macos` y `-windows`. Buzón publica `SHA256SUMS-linux`, así que no encontraba ningún archivo y la tarjeta decía «No disponible aquí». Ahora también lee `SHA256SUMS-linux`.

## English

### Fixes

- **Buzón "Not available here"**: when GitHub rate-limited unauthenticated requests, the Launcher found a release's files only from its `SHA256SUMS`, `-macos` and `-windows` checksum lists. Buzón publishes `SHA256SUMS-linux`, so it found no file and the card read "Not available here". It now reads `SHA256SUMS-linux` too.
