Nodalia Launcher 0.3.4 estrena los retratos nuevos de Código (Alan Turing), Ábaco (Carl Friedrich Gauss) y Orbe (John von Neumann).

*Nodalia Launcher 0.3.4 brings the new portraits of Código (Alan Turing), Ábaco (Carl Friedrich Gauss) and Orbe (John von Neumann).*

## Español

### Novedades

- **Iconos nuevos de tres apps**: Código ya no es Grace Hopper sino Alan Turing, Ábaco ya no es John Napier sino Carl Friedrich Gauss, y Orbe ya no es Johannes Kepler sino John von Neumann. Se ven en la lista, en las fichas y en el menú de aplicaciones de Linux. Los iconos van dentro del programa, así que hace falta esta versión para verlos.

## English

### What's new

- **New icons for three apps**: Código is no longer Grace Hopper but Alan Turing, Ábaco is no longer John Napier but Carl Friedrich Gauss, and Orbe is no longer Johannes Kepler but John von Neumann. They show in the list, on the cards and in the Linux applications menu. The icons are built into the program, so this version is needed to see them.
